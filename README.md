# ROS 2 Learning Workspace

A practical ROS 2 learning workspace containing examples and experiments covering ROS 2 nodes, topics, services, actions, parameters, custom interfaces, URDF, Xacro, launch files, and robot description.

## Workspace Structure

```text
ros2_ws/
└── src/
    ├── robot/
    ├── ros2_custom_interfaces/
    └── ros2_learning/
```

## Packages

### robot

The `robot` package is a CMake-based ROS 2 package used for learning robot description and visualization.

It contains examples related to:

* URDF
* Xacro
* Xacro macros
* Links and joints
* Joint limits
* Robot meshes
* Robot State Publisher
* Joint State Publisher GUI
* ROS 2 launch files
* Package share directories

Important files:

```text

├── launch/
```

## Building the Workspace

This workspace is intended to be used with ROS 2 Jazzy on Ubuntu 24.04 LTS.

First source ROS 2:

```bash
source /opt/ros/jazzy/setup.bash
```

Go to the workspace:

```bash
cd ~/ros2_ws
```

Build the workspace:

```bash
colcon build
```

After building, source the workspace:

```bash
source install/setup.bash
```

---

## Running ROS 2 Examples

After building and sourcing the workspace, available executables can be viewed with:

```bash
ros2 pkg executables ros2_learning
```

For example:

```bash
ros2 run ros2_learning hello_node
```

The exact executable names depend on the package configuration.

## Version Control

The following directories are generated by ROS 2 and are intentionally excluded from Git:

```text
build/
install/
log/
```

These directories do not need to be stored in the repository because they can be regenerated by running:

```bash
colcon build
```

Python cache and editor-generated files are also excluded through `.gitignore`.
